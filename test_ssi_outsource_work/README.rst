=========================================
Test Module - Outsource Work Object Mixin
=========================================

Test-only module for ``mixin.outsource_work_object``. It provides two
minimal concrete models used to prove that a model inheriting the mixin
can open its form view without setting ``_outsource_work_create_page``
explicitly, and that setting it to ``True`` inserts the Outsource Work
tab as expected.
