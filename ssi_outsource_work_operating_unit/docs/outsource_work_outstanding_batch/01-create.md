# Create Outsource Work Outstanding Batch

> **Module:** ssi_outsource_work_operating_unit
>
> **Extends:** ssi_outsource_work — model `outsource_work_outstanding_batch`, aksi
> `01-create`

## Additional Fields

When this module is installed, the create form gains one additional field, visible only
to users in the **Multiple Operating Unit** group
(`operating_unit.group_multi_operating_unit`):

- **Operating Unit**: the operating unit that owns this batch. Not required.
  Automatically filled from the current user's default operating unit (falls back to an
  operating unit assigned to the user in the active company, if any). Change if needed.

## Additional Post-Condition

- Every **Outsource Work Outstanding** generated by the inline **Populate** action
  carries the same **Operating Unit** as this batch, whoever pressed the button.

## Modified — Record Visibility

- The **Outstanding Batches** list is filtered by operating unit (record rule). A user
  only sees batches whose Operating Unit is one of the operating units assigned to them.
  This is not a Flow step.
