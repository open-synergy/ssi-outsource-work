=====================
Outsource Work Portal
=====================

Customer portal pages for the Outsource Work module. Adds the
``/my/outsource-works`` and ``/my/outsource-work-outstandings`` routes,
their templates, and the record rules that let a portal user see only
their own documents. Depends on the core ``portal`` add-on only, not on
``website``.


Bug Tracker
===========

Bugs are tracked on `GitHub Issues
<https://github.com/open-synergy/ssi-outsource-work/issues>`_. In case of
trouble, please check there if your issue has already been reported. If you
spotted it first, help us smash it by providing detailed and welcomed feedback.
